# Sayar Owl Academy

A modern English learning platform for Grade 10 students in Myanmar. Sayar Owl is a patient, encouraging AI tutor that breaks down grammar rules, explains sentence structure, and provides Myanmar translation context when it helps students understand better.

## What students can do

- **Ask Sayar Owl anything** — paste a sentence or grammar question and get a clear explanation of the "why."
- **Explore the Grade 10 syllabus** — open any unit and tap a skill card to start practicing.
- **Upload an exam paper** — get guided feedback on Myanmar matriculation-style English questions.
- **Practice with purpose** — every lesson ends with a tiny practice question so learning sticks.

## Built with

- [Lovable](https://lovable.dev)
- TanStack Start
- Tailwind CSS
- Lovable Cloud

```sh
npm i
npm run dev
```
